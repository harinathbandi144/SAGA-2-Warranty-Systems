# Automotive Warranty Management Platform

A Spring Boot microservices project for automotive warranty management.

## Tech Stack
- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Flyway
- Maven
- REST APIs

## Microservices

### Claim Service
- Create warranty claims
- Get claim by ID
- Get claims with pagination
- Update draft claims
- Submit claims
- Claim approval workflow (planned)

## Planned Services
- Vehicle Service
- Dealer Service
- Policy Service
- Settlement Service
- Notification Service
- API Gateway

## Architecture
Independent Spring Boot microservices maintained in a single Git repository.
